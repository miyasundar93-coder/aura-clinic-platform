Onboarding workflow

From clinic registration to website enquiry.

3 steps
01 · Register clinic
Enter clinic name, owner, contact information, location and specialty.
02 · Create login credentials
Set the clinic login email and generate a temporary password for first access.
03 · Generate enquiry entry point
Create a clinic-specific enquiry page and download its website link or embed button snippet.
Prototype note: this standalone demo saves clinic profiles in this browser only. Production login, central database, public URLs and enquiry delivery require a secure backend and hosting.

After onboarding

What the platform admin can download.

Clinic-specific enquiry page
A standalone HTML enquiry form branded with that clinic's name and contact details.
Website button snippet
A ready-to-copy button or iframe snippet for the website's “Enquiry Now” area.
Clinic access details
Download the username and temporary password to share securely with the clinic owner.
Security: this is a front-end prototype, not a production authentication system. Do not use real patient data or real passwords in this demo.
